# Fences

A Rust block:

```rust
fn main() {
    let x = (1, [2, 3]);
    println!("{x:?}");
}
```

A JSON block:

```json
{"a": [1, true, null]}
```

> A quoted fence:
>
> ```rust
> fn quoted() -> u8 {
>     7
> }
> ```
