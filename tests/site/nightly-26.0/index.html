Requirements

macOS 26.0 or later, on Apple silicon (arm64) only.

Install

  1. Download Leanmacs.dmg and open it.
  2. Drag Leanmacs.app onto Applications.
  3. Open it, and on first launch follow the steps below.

First launch

The app is ad-hoc signed and not notarized, so macOS blocks it the first time. Since macOS 15, Control-click > Open no longer gets past this. Instead:

  1. Open Leanmacs once. macOS says it cannot check it; click Done.
  2. Open System Settings > Privacy & Security, scroll down, and click "Open Anyway" beside the message about Leanmacs.
  3. Open Leanmacs again and confirm.

If that does not work, remove the quarantine flag in Terminal:

xattr -dr com.apple.quarantine /Applications/Leanmacs.app

Which build is installed

/Applications/Leanmacs.app/Contents/MacOS/editor --version

prints the version, the build ID, the commit and the core's tag.
